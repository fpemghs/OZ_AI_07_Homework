### < head > : 웹페이지의 부가 정보를 알려주는 부분을 그룹화하는 태그
### < body > : 웹페이지의 본문에 해당하는 부분을 그룹화하는 태그(웹페이지의 실제 화면)
### < h > : 헤딩, 제목등의 텍스트를 강조하는 부분에 사용하는 태그
### < p > : 문단을 나타낼때 쓰는 태그
### < hr > : 행으로 된 줄을 긋는 태그(열로 된 줄은 위치가 모호하기 때문에 없음)

### < ul > : 순서가 상관 없는 무작위 리스트에 사용하는 태그 , 밑에 < li >로 리스트를 내용을 추가 
### < ol > : 순서가 있는 리스트에 사용하는 태그, 밑에 < li >로 리스트 내용을 추가하며, type을 통해 여러가지 순서기법으로 표현가능
### < li > : < ul > < ol > 리스트 내부 내용 작성을 위한 태그

### < input > : 입력가능한 창을 만드는 태그, type을 통해 text, email, password등 다양한 형식으로 입력 가능

### < img > : 이미지를 불러오는 태그, src에 이미지 경로, alt에 이미지 로드 실패시 대체 택스트 입력 

### < table > : 행과 열로 이루어진 표를 작성하기 위한 태그
### < thead > : 테이블의 해드에 해당하는 부분을 그룹화하는 태그
### < th > : 테이블 해드에 내용(표 맨 윗부분 ID, 이름, 이메일 등)를 입력하는 태그
### < tbody > : 테이블의 바디(본문)에 해당하는 부분을 그룹화하는 태그
### < tr > : 테이블에 행으로 된 줄을 긋는 태그(각 td를 구분)
### < td > : 테이블 바디에 내용(2째 행 부터 시작되는 1, 홍길동, hong@example.com 등)을 입력하는 태그

### < a > : anchor의 약자로 일종의 하이퍼링크를 연결하는 태그(클릭시 입력된 위치로 연결된다)
